划线 📚

书里想划线的句子，用手指一划就好

读纸质书时想划线的那句话，一张照片就能留住。拍下封面和有好句子的那一页，应用会记住它出自哪本书、第几页。像用荧光笔一样，用手指在书页上划过，就只保存那一句。

使用方法

📖 添加书籍

拍下封面，书名和作者会自动填好。如果拍到了封底的条形码，ISBN 也会一并读取。保存前所有内容都可以修改。

📐 框选书页

把四个角对准书页，照片就会像纸张一样被拉平，文字识别得更清楚。

🖍️ 用手指划线

在想要的句子上划过，就只会选中那些字。双指放大可以划得更精确，还有橡皮擦和“全选”。页码也会自动识别。

🗂️ 我的摘录

保存的句子按书整理在书架里，随时翻看，支持全文搜索和收藏。

✨ 今日一句

每天从你保存的句子里挑出一句送到你面前，还能做成卡片分享。

你的摘录只留在你的设备上

文字识别在设备上完成，照片和摘录不会被发送到开发者的服务器。登录 iCloud 后，它们会通过你自己的 iCloud 账户在你的设备之间同步。详情请参阅隐私政策。

系统要求

  • iOS 17.0 或更高版本
